# Motion Particle Studio V5.2

独立运行的 2D 粒子与原生骨骼动画工作台。

## V5.2 数值控制更新
- 所有属性检查器中的数值输入框增加可拖动滑块。
- 保留原生 number 输入框上下微调箭头，不移除原有输入方式。
- 滑块拖动时数值框同步；数字输入、键盘输入和上下箭头修改时滑块同步。
- 滑块继承每个参数原本的 min / max / step，小数步长和负数范围均保留。
- 粒子属性、外观/尺寸、物理、路径和原生骨骼变换数值均使用同一套双向同步控件。
- Intro / Outro / 预热 / 骨骼周期等属性检查器数值设置也支持滑块。

## 运行
使用 Chrome 或 Edge 打开 `index.html`。
