# 粒子工坊 Particle Studio V2.0

无需安装 Spine。直接在浏览器制作 2D / 2.5D 粒子动画，并在本地导出文件。

## 文件
- `index.html`：页面结构
- `style.css`：界面样式
- `app.js`：粒子模拟、预设、项目管理与导出

## 使用
将三个文件放在同一个目录，直接打开 `index.html` 即可运行；也可部署到 GitHub Pages。

## 功能
- 18 个内置快速预设
- 2D / 2.5D 粒子预览
- 持续发射、瞬时爆发、常驻填充
- 发射区域、扩散、数量、速率、生命周期、速度、重力、风力、旋转、扰动
- 自定义贴图上传（PNG / WebP / JPG）
- Loop 循环预览、暂停、重播
- 保存 / 导入 JSON 项目
- 直接导出 WebM 动画、PNG 序列帧 ZIP、PNG 静帧

## 导出说明
- WebM 由浏览器 MediaRecorder 编码；透明通道支持情况取决于浏览器。
- PNG 序列帧按设定 FPS 和时长逐帧离线渲染后打包为 ZIP。
- GIF / MP4 未内置编码器，因此本版不显示虚假的 GIF / MP4 导出选项。可将 WebM 或 PNG 序列导入剪辑软件转换。
- 所有粒子模拟与贴图读取均在浏览器本地完成，不会自动上传素材。
